# Public API

aflib has no REST API. This file is the map of its public Go packages: what
each one is for and which exported identifiers matter most.

The complete exported surface is in [`docs/generated/`](generated/), the output
of `go doc -all` for each package, regenerated by `make doc`. The declarations
alone, without comments, are pinned in `testdata/api/<name>.golden`; a change to
one fails `make check` until `make api-golden` accepts it on purpose (see
[`architecture.md`](architecture.md)).

The module path is `github.com/agent-fox-dev/aflib`. It has three public
packages and no command.

## aflib

`github.com/agent-fox-dev/aflib`, the root package. It consists of `doc.go`, a
package doc comment that names the module and its two packages. It declares
nothing and imports nothing, and its golden file is empty.

## issuex

`github.com/agent-fox-dev/aflib/issuex`: a forge-neutral `Client` for GitHub and
GitLab. It declares repository, issue, label, comment and pull or merge request
operations, with forge detection, a shared request loop (bounded response
bodies, one rate-limit retry, a mapping from statuses to errors) and a no-op
client. Standard library only. Copied from agent-fox
(see [`architecture.md`](architecture.md)).

**The client.** `Client` (alias `ForgeClient`) is the interface. Its methods are
`Authenticated` and `Close`; `GetRepository`; for issues `CreateIssue`,
`ReadIssue`, `UpdateIssue`, `CloseIssue`, `ListIssues`, `AddComment`,
`ListComments`, `AddLabels`, `RemoveLabel` and `CreateLabel`; and for pull or
merge requests `CreatePullRequest`, `ReadPullRequest`, `ReadChangedFiles`,
`GetPRState`, `GetCIChecks`, `GetPRReviews`, `PostReviewComment`,
`MergePullRequest` and `ClosePullRequest`.

**Construction.** `New` takes a user agent; `NewWithOptions` takes `Options`;
`NewGitHub`, `NewGitLab` and `NewNoOp` build one adapter directly. `Options`
has the fields `BaseURL`, `Token`, `HTTPClient`, `UserAgent`, `NoOp`, `Repo`,
`RemoteURL` and `Dir`. An explicit `BaseURL` or `Token` takes precedence over the
environment ([`configuration.md`](configuration.md)). A host that names neither
forge is `ErrAmbiguousForge`, and nothing is sent to it.

**Forge detection.** `DetectForge` resolves a `ForgeType` (`ForgeTypeGitHub`,
`ForgeTypeGitLab` or `ForgeTypeUnknown`) from an explicit base URL, a remote
URL, the repository's host, the environment or the origin remote of a directory.
`RegisterAdapter` adds a factory for a `ForgeType`. `DetectRepo`, `ParseRemote`,
`ParseRepo` and `ParseIssueURL` parse remotes, repository paths and web URLs of
issues and pull or merge requests.

**Vocabulary.** `Repo`, `IssueRef`, `Issue`, `IssueThread`, `Comment`,
`CommentList`, `IssueList`, `IssueFilter`, `PullRequest`, `ChangedFile`,
`PRState`, `CheckRun`, `Review`, `Label`, `Repository`, `RepoPermissions` and
`User`; the request types `CreateIssueRequest`, `UpdateIssueRequest` and
`CreatePullRequestRequest`; and `MergeMethod` (`MergeMethodDefault`,
`MergeMethodMerge`, `MergeMethodSquash`, `MergeMethodRebase`), `MergeOptions`
and `MergeResult`.

**Errors.** The sentinels `ErrNoToken`, `ErrNotFound`, `ErrConflict`,
`ErrRateLimited`, `ErrUnsupportedForge` and `ErrAmbiguousForge`; `HTTPError` with
`HTTPErrorFromResponse`; and the predicates `IsNotFound`, `IsConflict`,
`IsRateLimited` and `IsNoToken`. A rate-limited request whose backoff is within
120 seconds is retried once; a longer one, or a second limit, is an error that
wraps `ErrRateLimited`.

**Limits.** `GitHubMaxBodyLength` and `GitLabMaxBodyLength` are the largest body
each forge accepts; `MaxBodyLength` returns the limit of a `Client`
(`BodyLimiter`). `MaxResponseBodyBytes` bounds every response body read by
`ReadResponse`, `ReadResponseBody` and `LimitResponseBody`. `SetGitHubSleep` and
`SetGitLabSleep` replace the sleep used for rate-limit backoff, for tests.

## jobqueue

`github.com/agent-fox-dev/aflib/jobqueue`: a durable, SQLite-backed job queue with
retry, per-key serialization, group serialization, progress tracking, crash
recovery and graceful shutdown. It runs over a `*sql.DB` the caller owns and
configures ([`architecture.md`](architecture.md)). Standard library and
`github.com/google/uuid`. Copied from hub.

**Construction.** `New` takes the database, a logger and options: `WithWorkers`
(default 4), `WithPollInterval` (default 5s) and `WithGracePeriod` (default 30s).
`InitSchema` creates the `jobs` table; `MigrateGroupKey` and `MigrateProgress`
are its two migrations.

**Handlers.** `Queue.Register` binds a job type to a `HandlerFunc` and an
optional `RetryPolicy`. `DefaultRetryPolicy` is Base 2s, Multiplier 2, Cap 2h,
MaxRetries 20. A handler must be idempotent, because crash recovery may
dispatch a job again. `JobIDFromContext` returns the id of the job a handler is
running, and `ContextWithJobID` sets it for tests.

**Enqueueing.** `Queue.Enqueue` takes `EnqueueParams` (`Type`, `Key`, `Nonce`,
`Payload`, `SubmittedBy`, `Group` and `ExcludeJobID`) and returns the job id and
whether the job duplicated an active one of the same type and key.

**Lifecycle.** `Queue.Start` performs crash recovery and launches the workers;
`Queue.Shutdown` asks them to stop, `Queue.Wait` waits up to the grace period,
and `Queue.Stop` does both.

**Jobs.** `Queue.CancelJob`, `Queue.RequeueDeadLetter` and `Queue.UpdateProgress`
change a job; `Queue.GetByID`, `Queue.ListByType`, `Queue.ListByKey`,
`Queue.ListByKeyPrefix` and `Queue.CountByStatus` read them, with `Job` and
`ListOpts`. The statuses are `StatusQueued`, `StatusRunning`, `StatusCompleted`,
`StatusFailed`, `StatusDeadLetter` and `StatusCancelled`; `ErrNotCancellable` is
returned for a job that cannot be cancelled.
